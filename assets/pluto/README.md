# Pluto texture

The source map does not provide complete, detailed image coverage of Pluto.
The bundled [pluto_complete.jpg](pluto_complete.jpg) is an AI-assisted
illustration based on the
[New Horizons global colour map](https://science.nasa.gov/resource/pluto-global-color-map/),
compiled from images taken by NASA's New Horizons spacecraft during its 2015
Pluto flyby.

AI generation was used to fill gaps in the source imagery and create a complete
texture for rendering. It also alters some observed detail, so this is an
illustrative texture, not a scientifically accurate map of Pluto's entire surface.

Source imagery credit: NASA/JHUAPL/SwRI.
